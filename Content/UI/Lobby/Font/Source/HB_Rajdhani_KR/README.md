# HB Rajdhani KR Regular

프로젝트용 커스텀 확장 폰트입니다. 공식 Rajdhani 배포판이 아닙니다.

- 영문 및 기존 문자는 Rajdhani Regular 원본의 윤곽과 폭을 유지합니다.
- 한글은 별도로 작성한 기하학적 자모 도형을 조합하여 생성했습니다.
- 현대 한글 완성형 U+AC00–U+D7A3: 11,172자
- 호환 자모 U+3131–U+3163: 51자
- 현대 조합 자모 U+1100–U+1112, U+1161–U+1175, U+11A8–U+11C2: 67자
- 옛한글 및 한자는 이번 확장 범위에 포함하지 않습니다.
