# TestPCG_Preview 직접 탐사

`/Game/Levels/Test_CW/Maps/TestPCG_Preview`에서 1인 PIE Play를 시작한다.
전체 방 로딩 후 첫 모험방 내부에 관찰용 Pawn이 배치된다. 뷰포트를 클릭하면 이동할 수 있다.

| 조작 | 동작 |
| --- | --- |
| 마우스 / WASD | 시점 회전 / 자유 비행 |
| Q / E | 하강 / 상승 |
| Shift | 이동 속도 5배 |
| Tab | 전체 보기와 탐사 전환, 탐사 위치 유지 |
| 1 / 2 / 3 | 전체 / 1층 / 2층 배치 보기 |
| Home | 시작방 내부로 복귀 |
| PageUp / PageDown | 이전 / 다음 방 내부로 이동 |
| R / T | 새 시드 / 같은 시드 재생성 |

전체 보기에서 WASD는 화면 이동, Q/E는 확대/축소다.
재생성 중에는 전체 보기로 전환하고, 완료되면 새 시작방으로 돌아온다.
관찰용 Pawn에 충돌이 없으므로 벽·닫힌 문·천장·바닥을 통과한다.
방 간격과 연결 화살표는 기존 프로토 방식이며, 실제 통로나 문 정렬을 구현한 것은 아니다.

## 검증

- UE 5.7 Editor Development 빌드 성공.
- 기존 PCG 자동 검사 2개 통과: 256개 시드 규칙 검사와 잘못된 배치 거부 검사.
- 첫 실행 시 방 13개 전체 로딩, 관찰 Pawn 1개 생성·빙의·카메라 연결 확인.
- 시야 앞 Wall_Corner 메시가 약 697.51cm에서 충돌 검사에 걸리는 것을 확인한 뒤,
  실제 이동 함수로 약 997.51cm 이동하여 표면을 통과하고 목표 좌표에 도달함을 검증.
- 금속 문 메시 경계의 양쪽을 약 342.64cm 이동하여 통과 확인.
  이 문은 복합 Visibility 검사에는 걸리지 않아, 충돌 차단 표면 검증은 위 벽 검사로 확인함.
- 마우스 델타에 따른 시점 회전, 가속 상승 이동, 전체 보기 왕복 및 위치 유지 확인.
- 13개 방 이동, 이전/다음 인덱스 순환 확인.
- 동일 시드 1272190408 재생성: 같은 13개 방 배치, 동일 Pawn 재사용, 시작방 좌표 복귀.
- 새 시드 652556797 재생성: 다른 11개 방 배치, 동일 Pawn 재사용, 시작방 좌표 복귀.
- 두 재생성 모두 이전 레벨 잔여 0개, Pawn 1개, 모든 방 로딩 완료.
- 최종 TestPCG_Preview 저장 확인, 미저장 패키지 0개.
- 원본 두 방, 모듈 복제본, 기존 맵/리다이렉터는 작업 시작 전 해시와 일치.

이동 검증은 키보드 입력 처리에서 사용하는 Fly 함수를 PIE에서 호출하는 방식이다.
실제 키보드·마우스 장치를 자동 조작한 테스트는 아니다.
패키징 실행과 멀티플레이는 이번 검증 범위에 포함되지 않는다.

증거: `exploration_checks.json`, `door_crossing.json`, `replay.json`, `new_seed.json`,
`preserved_assets.json`, `interior.png`, `boss_interior.png`.
