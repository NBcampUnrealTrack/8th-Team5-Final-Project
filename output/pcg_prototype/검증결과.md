# PCG 방 배치 프로토 검증

검증 환경: UE 5.7, HeavenBreachEditor Win64 Development, 1인 PIE.

## 실행

`/Game/Levels/Test_CW/Maps/TestPCG`를 열고 Play를 누른다. 뷰포트를 클릭하면 키 입력을 받는다.
맵 시작 시 새 시드로 방 전체를 생성한다. 플레이어 Pawn은 생성하지 않는다.

- R: 새 시드로 재생성. 기존 방을 모두 제거한 후 생성한다.
- T: 현재 시드 재현.
- 1 / 2 / 3: 전체 / 1층 / 2층 보기.
- WASD: 카메라 이동. Q / E: 확대 / 축소.
- READY: 모든 방 레벨이 로드되어 표시되는 상태.

## 현재 범위

Adventure01 복제본을 모험·회복·강화 역할에 사용하며, Boss 복제본은 보스 역할에 사용한다.
복제본의 전역 환경 액터를 제거하고 중심을 정렬했다. 원본 두 맵의 최종 내용은 보존했다.
층별 방 배치, 역할, 연결 관계와 실제 모듈 로딩을 확인하는 프로토다.

**연결선은 계획된 연결 관계를 표시한다. 통행 가능한 문 구멍, 문 정렬, 보스 연결 통로,
층간 계단은 생성하지 않는다.** 방 외곽의 기하학적 바운딩 박스로 겹침을 검사한다.
플레이어 이동, 문 작동, 회복·강화 기능, AI 내비게이션, 멀티플레이는 이번 검증에 포함되지 않는다.
패키지 빌드 실행도 별도 검증 대상이다. 검증 중 백그라운드 에디터에서는 최초 로딩에 약 40초가 걸렸다.

프로젝트의 기존 Skill/Augment 카드 구조체 초기화 관련 시작 로그 오류는 별도 문제이며,
이번 PCG 검사 2개는 오류·경고 없이 통과했다.
